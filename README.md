# Brokers Land — เว็บไซต์นายหน้าขายที่ดิน

เว็บไซต์สำหรับลงประกาศขายที่ดิน ให้คนทั่วไปเข้ามาดู ค้นหา และติดต่อสอบถามได้ พร้อมระบบหลังบ้าน (Admin) สำหรับจัดการประกาศและตั้งค่าเว็บไซต์

## ความสามารถ

**หน้าเว็บสำหรับผู้เข้าชม**
- หน้าแรก: ค้นหาที่ดิน, ประกาศแนะนำ, ค้นหาตามจังหวัด
- รายการประกาศ: กรองตาม จังหวัด / ประเภท / สถานะ / ช่วงราคา / ขนาด (ไร่) และเรียงลำดับ
- หน้ารายละเอียดที่ดิน: ที่ตั้ง (จังหวัด อำเภอ ตำบล ถนน), ขนาด **ไร่ – งาน – ตารางวา** พร้อมพื้นที่รวม (ตร.ว. / ตร.ม.),
  ราคารวม ราคาเฉลี่ยต่อ ตร.ว. และต่อไร่, เอกสารสิทธิ์, ทางเข้าออก, สาธารณูปโภค, แกลเลอรีรูป, แผนที่ปักหมุด + ลิงก์ Google Maps
- ฟอร์มสอบถาม / ฝากขาย, ปุ่มโทร และปุ่ม LINE
- รองรับมือถือ

**ระบบหลังบ้าน (`/admin`)**
- แดชบอร์ด: จำนวนประกาศแยกสถานะ ยอดเข้าชม ข้อความล่าสุด
- เพิ่ม / แก้ไข / ลบประกาศ, อัปโหลดรูปหลายรูป, ตั้งรูปปก, คำนวณพื้นที่และราคาต่อ ตร.ว. อัตโนมัติ, คลิกแผนที่เพื่อปักหมุด
- เปลี่ยนสถานะ พร้อมขาย / ติดจอง / ขายแล้ว, ซ่อนหรือแสดงประกาศ, ตั้งเป็นประกาศแนะนำ
- กล่องข้อความจากผู้สนใจ
- **ตั้งค่าเว็บไซต์**: ชื่อเว็บ, สโลแกน, ข้อความหน้าแรก, เบอร์โทร, LINE, อีเมล, Facebook, ที่อยู่, สีหลักของเว็บ,
  จำนวนประกาศต่อหน้า, เปิด/ปิดการแสดงราคา
- จัดการบัญชีผู้ดูแล: เปลี่ยนรหัสผ่าน, เพิ่ม/ลบผู้ดูแล

## วิธีติดตั้งและรัน

ต้องใช้ Node.js เวอร์ชัน 22.13 ขึ้นไป (ใช้ SQLite ที่มีในตัว Node ไม่ต้องติดตั้งฐานข้อมูลแยก)

```bash
npm install
npm start
```

เปิด http://localhost:3000 สำหรับหน้าเว็บ และ http://localhost:3000/admin สำหรับหลังบ้าน

บัญชีผู้ดูแลเริ่มต้น: `admin` / `admin1234` — **กรุณาเปลี่ยนรหัสผ่านทันทีที่เมนู "บัญชีผู้ดูแล"**

ครั้งแรกที่รันจะมีประกาศตัวอย่าง 3 รายการ ลบได้จากหลังบ้าน (หรือตั้ง `SEED_SAMPLE=0` ก่อนรันครั้งแรกเพื่อไม่ให้สร้าง)

### ตัวแปรสภาพแวดล้อม (ไม่บังคับ)

| ตัวแปร | ความหมาย |
|---|---|
| `PORT` | พอร์ตเซิร์ฟเวอร์ (ค่าเริ่มต้น 3000) |
| `SESSION_SECRET` | คีย์สำหรับเข้ารหัส session (ถ้าไม่ตั้ง ระบบจะสร้างให้อัตโนมัติและเก็บไว้ใน `data/`) |
| `ADMIN_USERNAME`, `ADMIN_PASSWORD` | ชื่อผู้ใช้/รหัสผ่านของผู้ดูแลคนแรก (ใช้ตอนสร้างฐานข้อมูลครั้งแรกเท่านั้น) |
| `COOKIE_SECURE=1` | ตั้งเมื่อเว็บรันผ่าน HTTPS |
| `DATA_DIR` | โฟลเดอร์เก็บไฟล์ฐานข้อมูล (ค่าเริ่มต้น `./data`) |
| `SEED_SAMPLE=0` | ไม่สร้างประกาศตัวอย่าง |

## โครงสร้างโปรเจกต์

```
server.js              จุดเริ่มต้นของเซิร์ฟเวอร์ (Express)
src/db.js              ฐานข้อมูล SQLite, ค่าตั้งต้น, ข้อมูลตัวอย่าง
src/helpers.js         ฟังก์ชันคำนวณพื้นที่ (ไร่/งาน/ตร.ว.), จัดรูปแบบราคา, CSRF
src/routes/public.js   หน้าเว็บสำหรับผู้เข้าชม
src/routes/admin.js    ระบบหลังบ้าน
views/                 เทมเพลต EJS
public/                CSS และรูปภาพ
data/                  ไฟล์ฐานข้อมูล (สร้างอัตโนมัติ)
uploads/               รูปที่อัปโหลด (สร้างอัตโนมัติ)
```

> สำรองข้อมูล: คัดลอกโฟลเดอร์ `data/` และ `uploads/` เก็บไว้

หน่วยพื้นที่: 1 ไร่ = 4 งาน = 400 ตารางวา, 1 งาน = 100 ตารางวา, 1 ตารางวา = 4 ตารางเมตร
